# Previsão de Carga de Energia — Subsistema SE (ONS)

Pipeline de dados e modelagem para previsão de carga diária de energia (MWmed) do subsistema Sudeste/Centro-Oeste (`SE`) para os próximos 7 dias, usando dados abertos do ONS.

*(Resultados e instruções finais serão atualizados após a execução do pipeline.)*
